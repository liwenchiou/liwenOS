# 《我決定不再把自己賣給鳥工作》－引言筆記

## 核心觀念

> 成為「選職者」，而不是「求職者」。

得到理想工作並不是靠運氣，而是透過一套可以學習、可以練習的策略與流程──**選職（Reverse the Search）**。

---

# 求職者 vs 選職者

| 求職者 | 選職者 |
| :--- | :--- |
| 目標不明確 | 清楚知道自己想要什麼 |
| 求職過程忙碌、焦慮且疲憊 | 求職過程有方向，一切都在掌控之中 |
| 不斷累積學歷、證照 | 想辦法展現自己的能力與價值 |
| 認為大量投履歷比較容易找到工作 | 避免大量線上投遞，用更有效率的方式吸引公司注意 |
| 不想錯過任何機會，因此來者不拒 | 將自己定位成目標公司正在尋找的人才 |
| 面試是在說服公司錄取自己 | 面試是與公司討論彼此是否適合合作 |
| 著重介紹自己過去的成就 | 著重討論公司目前的需求，以及自己如何解決問題 |
| 希望讓面試官留下好印象 | 希望讓面試官把自己視為未來的同事 |
| 最終得到一份錄取通知 | 同時收到多份錄取通知，甚至讓公司主動爭取自己 |

---

# 投入選職前的兩大關卡

## 1. 意識到自己需要改變

很多人明明不喜歡現在的工作，卻選擇繼續忍耐。

就像鞋子裡有一顆小石頭，不願停下來把它拿掉，而是不斷往前走，最後甚至習慣了疼痛。

---

## 2. 知道該如何開始

大部分的人都在重複相同的流程：

> 修改履歷 → 投履歷 → 等待 → 面試 → 錄取 → 接受工作 → 不喜歡工作 → 再次開始求職

如果流程沒有改變，結果通常也不會改變。

---

# 阻止自己行動的藉口

當想改變時，大腦往往會開始替自己找理由：

1. 我想要的工作競爭太激烈。
2. 我的履歷一定會被刷掉。
3. 就算進入面試，也會因為年紀、性別、背景等不可控因素被淘汰。
4. 我根本不知道自己真正想做什麼。

---

# 如果……

如果以下這些事情都不是幻想，而是合理且可以達成的呢？

- 求職方式和以前完全不同。
- 公司主動邀請你面試，而不是你一直投履歷。
- 找到真正理想的工作，讓職涯持續向上發展。
- 下一份工作能帶來更好的薪資、更多自由、更大的彈性，以及理想的生活。

即使過程不一定輕鬆，但只要想到未來想過的生活，就值得投入。

---

# 選職者的共同特質

- 全力投入自己的職涯，成為人生的主人。
- 不抱怨面試制度不好。
- 不怪罪目前工作的處境。
- 不把結果歸咎於運氣或命運。
- 相信自己一定能找到更好的選擇。

> **我注定要成為選職者。**

---

# 魔術方塊的比喻

大多數人的求職方式，就像第一次玩魔術方塊。

不停地轉動每一面，偶爾拼出一個顏色，就以為快成功了；但花了很多時間，最後仍然解不開，因此感到挫敗。

選職者則不同。

他們知道解開魔術方塊的方法，知道每一步該怎麼做，也願意反覆練習，因此能更快完成目標。

成功不是因為天賦，而是因為掌握了正確的方法。

---

# 我的心得

這本書想傳達的不是「如何找到工作」，而是：

> **不要用求職者的思維找工作，而要用選職者的思維經營自己的職涯。**

真正的差別不是能力，而是策略。

當知道正確的方法後，每一步都會更有方向，也更有信心；即使還不知道下一步要做什麼，也能透過這套方法逐步釐清自己的職涯方向。
