# ✦ liwen OS — 個人數位大腦與生活儀表板

> *將散落在各地的工作排程、待辦清單與隨手筆記，收攏為一個安靜、專注且井然有序的個人中心。*

---

## 關於這座數位大腦

在每天的工作與生活中，我們經常需要在大大小小的分頁之間不斷跳轉：看行事曆確認下一場會議、開待辦軟體檢查剩餘任務、再打開筆記工具找尋先前的紀錄。大量的注意力就這樣消耗在視窗之間的切換。

* *liwen OS** 是一個為專注而生的「個人數位大腦」。它的目標很單純——讓你只要打開一個頁面，就能看清**今天要參加的會議**、**該搞定的待辦事項**、以及**所有沉澱下來的筆記知識**。不再讓工具打擾你的心流，把專注力留給真正重要的事情。

---

## 你可以用它做什麼？

### 1. 🗓️ 掌控每天的行程與會議筆記
- **一目瞭然的時間軸**：在「今日儀表板」與「行事曆時間軸」中，清晰查看今天的排程與當下的時間進度。
- **行程關聯筆記**：點擊任一場會議或行程，即可為其開設**行程會議筆記與紀錄**。不管是開會紀錄、待辦備忘還是討論靈感，寫完即**自動保存**，下次點擊同一個行程即可立刻看見對應筆記。

### 2. ✅ 管理與落實待辦清單
- **集中管理所有事項**：在一個介面內快速新增、編輯、打勾完成每日任務。
- **重要項目優先標示**：還沒完成的任務自動維持在視覺焦點，完成的任務俐落歸檔，視覺乾淨不干擾。

### 3. 📝 建立個人的 Markdown 知識庫
- **資料夾整理與拖拉收納**：左側的專案筆記目錄就像個人電腦裡的資料夾一樣，你可以輕鬆展開與收折分類，也能點擊並修改筆記標題與位置。
- **純粹且放心的寫作體驗**：支援 Markdown 語法編輯與即時預覽，寫作過程會**雲端靜默自動保存**，中途離開視窗或臨時關閉，文字也不會遺失。
- **完整保留檔案掌握權**：所有筆記皆是以常見的 `.md` 檔案形式存放在硬碟中，能隨時匯出、備份與移轉。

### 4. 💡 快捷記錄隨手靈感 (Scratchpad)
- 當有臨時的聯絡事項、轉瞬即逝的點子或隨手手稿需要抄寫時，打開「隨手筆記」直接鍵入即可，不需要為存檔和取檔名煩惱。

### 5. 📊 每日自動彙整日報 (Report)
- 一天的尾聲，系統可以幫你自動將「今天開的會議與對應紀錄」、「完成的任務」交叉整理為一份清楚的每日日報。
- 無論是想留一份記錄給未來的自己，或是複製產出的 Markdown 報表傳給團隊成員，一鍵就能輕鬆完成。

## 設計理念

- **靜謐而舒適的視覺**：深色低調的質感介面，降低長時間盯著螢幕的眼睛負擔，將螢幕的主角歸還給你的文字與任務。
- **不打擾的防禦性存檔**：無論是會議筆記彈窗還是知識庫文章，皆具備防抖動與關閉前的雙重自動寫入保護，真正做到「只管專心寫，剩下的交給系統」。
